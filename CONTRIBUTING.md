# Contributing to PromptForge

Thank you for contributing to PromptForge!

## Quick Development Setup
1. Clone your fork locally.
2. Open `chrome://extensions/` in Chrome or any Chromium browser.
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the `promptforge` directory.
5. Make changes to the code and refresh the extension card in `chrome://extensions/`.

## Pull Request Guidelines
- Follow Manifest V3 specifications.
- Keep the offline heuristics engine self-contained and dependency-free.
- Test your changes against Claude.ai, ChatGPT, and Copilot text inputs before opening a PR.
